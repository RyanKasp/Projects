Financial Data Retriever

A Python program that retrieves financial information for a user-entered stock ticker and presents it in a formatted table.

Features
Retrieves company name, industry, and market capitalization
Displays historical cash and total debt
Calculates key valuation metrics:
Trailing P/E
Forward P/E
Price-to-book ratio
Price-to-free-cash-flow ratio
Tools

Python · pandas · yfinance

Installation
pip install yfinance pandas
Usage

Run the program:

python "Financial Data Retriever.py"

Enter a ticker symbol when prompted:

Enter Ticker Symbol: AAPL

The program will retrieve the company’s available financial data and display it in the terminal.

Note

Financial data availability varies by company and depends on information provided through Yahoo Finance.
